# 翻译指令模板

将下列英文新闻条目翻译为简体中文，面向受过良好教育的中国大陆读者。

## 要求

- **标题**：准确简洁，保留机构名/地名的英文缩写（如 NASA、MIT、APA）
- **内容**：流畅自然，意译而非逐字直译，控制在 60-100 字之间
- **语气**：新闻报道风格，客观中性

## 输出格式

严格输出以下 JSON 结构，不要包含任何 markdown 代码块符号（不要 ```json）：

```
[
  {
    "index": 1,
    "title": "中文标题",
    "content": "60-100字的中文摘要"
  },
  {
    "index": 2,
    "title": "...",
    "content": "..."
  }
]
```
